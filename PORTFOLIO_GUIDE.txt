HOW TO VIEW YOUR PORTFOLIO LOCALLY:
─────────────────────────────────

OPTION 1: Direct Browser Open
──────────────────────────────
1. Open File Explorer
2. Navigate to: d:\portfolio_1\
3. Double-click: index.html
4. Portfolio will open in your default browser
5. All features are ready to use!

OPTION 2: Using Local Web Server (Recommended)
───────────────────────────────────────────────
1. Open Command Prompt or PowerShell
2. Navigate to: cd d:\portfolio_1\
3. If Python is installed, run:
   python -m http.server 8000
4. Open browser and go to: http://localhost:8000/
5. Your portfolio loads from local server

OPTION 3: Python SimpleHTTPServer Alternative
──────────────────────────────────────────────
1. Open Command Prompt
2. Navigate to: cd d:\portfolio_1\
3. Run: python -m SimpleHTTPServer 8000
4. Visit: http://localhost:8000/

OPTION 4: Node.js HTTP Server
──────────────────────────────
1. If Node.js installed, install http-server:
   npm install -g http-server
2. Navigate to: cd d:\portfolio_1\
3. Run: http-server
4. Visit provided URL (usually http://127.0.0.1:8080)

TROUBLESHOOTING:
────────────────
If images don't load:
- Ensure public/ folder exists in d:\portfolio_1\
- Check that all image files are present:
  * passport.jpg
  * smartderm.jpg
  * Buildpro.jpg
  * interviewnest.jpg

If PDF download doesn't work:
- Verify RiyaUpadhyay_AI-1.pdf exists in public/ folder
- Check browser console for errors (F12)
- Try in different browser

If animations are slow:
- Close other browser tabs
- Check browser GPU acceleration settings
- Try a different browser
- Reduce screen resolution temporarily

SHARING YOUR PORTFOLIO:
──────────────────────
Once ready to deploy:
1. Use GitHub Pages
   - Create GitHub repo "portfolio"
   - Push all files (include public/ folder)
   - Enable Pages in settings
   
2. Use Netlify
   - Drag & drop folder to Netlify
   - Get live link instantly
   
3. Use Vercel
   - Connect GitHub or upload files
   - Get custom domain option

4. Use shared hosting
   - FTP/SFTP upload to server
   - Ensure public/ folder is included
